Polish for the floating preview and blur, on Mac and Windows.

## What's new since beta.1

- **Copy confirms.** The Copy button in the floating preview turns into a green check for a moment after copying.
- **Preview buttons react** to hover and press, and their tooltips look like the toolbar's (with shortcuts and hints).
- **Strips and tall captures get a standard preview.** When a capture is wider than 3:1 or taller than 1:2, the floating preview keeps a 16:9 size and fits the image inside, so its buttons stay usable.
- **A new blur stays selected,** so its strength slider works right away.

On Mac, Snapkit 0.3.0-beta.1 offers this update itself: click **Install** when it asks, or use **Check for Updates…** in the menu bar icon. On Windows, beta users get a notification; download and install it over the old one.

## Shortcuts

`⌥⇧Z` (Windows: `Alt+Shift+Z`) capture an area · `⌥⇧X` last area · `⌥⇧T` text (OCR) · `⌘⇧9` full screen · `⌘⇧1` history · `⌘⇧2` settings (Windows: Ctrl instead of ⌘). All changeable in Settings → Shortcuts.

## Install

**macOS 14 or newer (Apple Silicon or Intel):** download `Snapkit-0.3.0-beta.2-mac.dmg`, open it and drag Snapkit to Applications, replacing the old one.
Snapkit is signed with its own certificate, not a paid Apple Developer ID, so macOS blocks the first launch:
open Snapkit once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
(Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Snapkit.app`.)
Then allow **Screen Recording** when asked, and quit and reopen Snapkit. Coming from 0.2, macOS asks for Screen Recording once more; if captures only show the wallpaper, remove Snapkit from the list with – and add it back.

**Windows (x64):** run `Snapkit-0.3.0-beta.2-win-x64-setup.exe`. SmartScreen warns about an unknown publisher: click **More info → Run anyway**.
If something misbehaves, the log is at `%APPDATA%\Snapkit\logs\main.log`; please attach it to a bug report.
