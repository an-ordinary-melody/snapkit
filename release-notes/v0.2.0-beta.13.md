Thirteenth beta of Snapkit, a fast screenshot tool for macOS and Windows.

## What's new since beta.12

- **Capture Text (OCR).** Select an area and press `X` (or the scan-eye button) to read its text. The text panel shows it so you can check, edit or join it into one line before copying. **Capture Text** (`⌥⇧T`, Windows: `Alt+Shift+T`, also in the menu bar) goes straight to reading. Set "Copy text" to "Copy right away" in Settings to skip the panel.
- **Reads English and Vietnamese**, offline and private: Apple's Vision on macOS (Vietnamese needs macOS 14 or newer), Windows' own OCR on Windows. Windows has no Vietnamese OCR, so with "Read Vietnamese" on, Snapkit uses Tesseract for it; it downloads about 7 MB of language data the first time.
- **Text from older captures:** the floating preview and History can read text too.

The first text read on a Mac can take up to a minute while macOS prepares its text models; after that it takes well under a second.

Beta users get a notification about this release; download and install it over the old one.

## Shortcuts

`⌥⇧Z` (Windows: `Alt+Shift+Z`) capture an area · `⌥⇧X` last area · `⌥⇧T` text (OCR) · `⌘⇧9` full screen · `⌘⇧1` history · `⌘⇧2` settings (Windows: Ctrl instead of ⌘). All changeable in Settings → Shortcuts.

## Install

**macOS (Apple Silicon only):** download `Snapkit-0.2.0-beta.13-mac-arm64.dmg`, open it and drag Snapkit to Applications.
Snapkit isn't signed with an Apple Developer ID yet, so macOS blocks the first launch:
open Snapkit once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
(Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Snapkit.app`.)
Then allow **Screen Recording** when asked, and quit and reopen Snapkit. After updating, macOS may ask for Screen Recording again.

**Windows (x64):** run `Snapkit-0.2.0-beta.13-win-x64-setup.exe`. SmartScreen warns about an unknown publisher: click **More info → Run anyway**.
If something misbehaves, the log is at `%APPDATA%\Snapkit\logs\main.log`; please attach it to a bug report.
