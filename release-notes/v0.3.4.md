## What's new since 0.3.3

- **Liquid Glass: Settings, History and the editor are fully glass (Mac).** With the Liquid Glass theme, each window is one sheet of glass over soft violet (light) or teal (dark) backgrounds, so it looks the same on any desktop.
- **Sliders and switches use the native macOS glass knob** in glass Settings.
- **Native macOS 26 controls.** The Mac app is now built so macOS draws its standard controls in the macOS 26 style.

On Mac, Snapkit offers this update itself: click **Install Update** when it asks, or use **Check for Updates…** in the menu bar icon. On Windows nothing changed; you can skip this one.

## Shortcuts

`⌥⇧Z` (Windows: `Alt+Shift+Z`) capture an area · `⌥⇧X` last area · `⌥⇧T` text (OCR) · `⌘⇧9` full screen · `⌘⇧1` history · `⌘⇧2` settings (Windows: Ctrl instead of ⌘). All changeable in Settings → Shortcuts.

## Install

**macOS 14 or newer (Apple Silicon or Intel):** download `Snapkit-0.3.4-mac.dmg`, open it and drag Snapkit to Applications, replacing the old one.
Snapkit is signed with its own certificate, not a paid Apple Developer ID, so macOS blocks the first launch:
open Snapkit once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
(Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Snapkit.app`.)
Then allow **Screen Recording** when asked, and quit and reopen Snapkit. Coming from 0.2, macOS asks for Screen Recording once more; if captures only show the wallpaper, remove Snapkit from the list with – and add it back.

**Windows (x64):** run `Snapkit-0.3.4-win-x64-setup.exe`. SmartScreen warns about an unknown publisher: click **More info → Run anyway**.
If something misbehaves, the log is at `%APPDATA%\Snapkit\logs\main.log`; please attach it to a bug report.
