Mac update checks that don't get in the way, and simpler version numbers.

## What's new since 0.3.0-beta.2

- **Update checks never leave Settings stuck (Mac).** Check now in Settings → About and Check for Updates… in the menu bar icon show the answer in Settings → About. A window opens only when there's an update. Before, the "You're up to date" box could hide behind other apps and leave Settings not responding to clicks.
- **Mac updates install from inside the app,** including from 0.3.0-beta.1 and 0.3.0-beta.2, which didn't see newer betas.
- **Simpler version numbers.** Snapkit now counts up normally: this is 0.3.3, the next is 0.3.4. The site's changelog lists the earlier betas as 0.2.1 to 0.3.2.

On Mac, Snapkit offers this update itself: click **Install Update** when it asks, or use **Check for Updates…** in the menu bar icon. On Windows, you get a notification; download and install it over the old one.

## Shortcuts

`⌥⇧Z` (Windows: `Alt+Shift+Z`) capture an area · `⌥⇧X` last area · `⌥⇧T` text (OCR) · `⌘⇧9` full screen · `⌘⇧1` history · `⌘⇧2` settings (Windows: Ctrl instead of ⌘). All changeable in Settings → Shortcuts.

## Install

**macOS 14 or newer (Apple Silicon or Intel):** download `Snapkit-0.3.3-mac.dmg`, open it and drag Snapkit to Applications, replacing the old one.
Snapkit is signed with its own certificate, not a paid Apple Developer ID, so macOS blocks the first launch:
open Snapkit once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
(Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Snapkit.app`.)
Then allow **Screen Recording** when asked, and quit and reopen Snapkit. Coming from 0.2, macOS asks for Screen Recording once more; if captures only show the wallpaper, remove Snapkit from the list with – and add it back.

**Windows (x64):** run `Snapkit-0.3.3-win-x64-setup.exe`. SmartScreen warns about an unknown publisher: click **More info → Run anyway**.
If something misbehaves, the log is at `%APPDATA%\Snapkit\logs\main.log`; please attach it to a bug report.
