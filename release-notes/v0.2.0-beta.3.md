Third beta of Snapkit, a fast screenshot tool for macOS and Windows. This one is mostly Windows fixes.

## What's new since beta.2

- **Shortcuts held by another app now come back.** If another app is using one of Snapkit's shortcuts, Snapkit keeps trying and takes it as soon as that app quits (before, it stayed dead until Snapkit restarted). Settings → Shortcuts marks a shortcut another app holds right now, and a taken capture shortcut at startup shows a notification instead of a blocking error box.
- **Editor on small or scaled screens (e.g. Windows at 150%):** the editor's tools no longer run past its edges, where they couldn't be clicked; they wrap onto a second row.
- **Windows: text is 32 px by default** (easier to read at Windows' usual display scaling). macOS stays at 20 px. Changeable in Settings → Tools.
- Behind the scenes: the end-to-end tests now also run on Windows, at 100% and 150% display scaling.

Beta users get a notification about this release; download and install it over the old one.

## Shortcuts

`⌥⇧Z` (Windows: `Alt+Shift+Z`) capture an area · `⌘⇧9` full screen · `⌘⇧1` history · `⌘⇧2` settings (Windows: Ctrl instead of ⌘). All changeable in Settings → Shortcuts.

## Install

**macOS (Apple Silicon only):** download `Snapkit-0.2.0-beta.3-mac-arm64.dmg`, open it and drag Snapkit to Applications.
Snapkit isn't signed with an Apple Developer ID yet, so macOS blocks the first launch:
open Snapkit once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
(Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Snapkit.app`.)
Then allow **Screen Recording** when asked, and quit and reopen Snapkit. After updating, macOS may ask for Screen Recording again.

**Windows (x64):** run `Snapkit-0.2.0-beta.3-win-x64-setup.exe`. SmartScreen warns about an unknown publisher: click **More info → Run anyway**.
If something misbehaves, the log is at `%APPDATA%\Snapkit\logs\main.log`; please attach it to a bug report.
