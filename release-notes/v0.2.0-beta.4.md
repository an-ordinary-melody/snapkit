Fourth beta of Snapkit, a fast screenshot tool for macOS and Windows.

## What's new since beta.3

- **Zoom in the background editor:** Ctrl + scroll zooms the preview around the mouse pointer (on a Mac also ⌘ + scroll or a trackpad pinch), and you can scroll around when zoomed in. **Ctrl + 0** (⌘0) fits it back to the window; Ctrl + / Ctrl − zoom in steps, and the % badge in the corner also fits. The image and your drawings are redrawn sharp at every zoom level.
- **Windows: text is 26 px by default** (was 32). macOS stays at 20 px. Changeable in Settings → Tools.

Beta users get a notification about this release; download and install it over the old one.

## Shortcuts

`⌥⇧Z` (Windows: `Alt+Shift+Z`) capture an area · `⌘⇧9` full screen · `⌘⇧1` history · `⌘⇧2` settings (Windows: Ctrl instead of ⌘). All changeable in Settings → Shortcuts.

## Install

**macOS (Apple Silicon only):** download `Snapkit-0.2.0-beta.4-mac-arm64.dmg`, open it and drag Snapkit to Applications.
Snapkit isn't signed with an Apple Developer ID yet, so macOS blocks the first launch:
open Snapkit once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
(Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Snapkit.app`.)
Then allow **Screen Recording** when asked, and quit and reopen Snapkit. After updating, macOS may ask for Screen Recording again.

**Windows (x64):** run `Snapkit-0.2.0-beta.4-win-x64-setup.exe`. SmartScreen warns about an unknown publisher: click **More info → Run anyway**.
If something misbehaves, the log is at `%APPDATA%\Snapkit\logs\main.log`; please attach it to a bug report.
