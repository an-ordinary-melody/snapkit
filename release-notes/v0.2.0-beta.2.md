Second beta of Snapkit, a fast screenshot tool for macOS and Windows.

## What's new since beta.1

- **Smaller downloads:** the Mac installer is 77 MB (was 93 MB) and the Windows installer 71 MB (was 78 MB). Snapkit now ships only Chromium's English language files and uses stronger DMG compression.
- **Full-screen capture is now `⌘⇧9`** (was `⌘⇧5`, which is also macOS's own screenshot toolbar). If you never changed it, it switches by itself; you can pick another in Settings → Shortcuts.
- Behind the scenes: an end-to-end test run with about 100 checks, one for each bug fixed so far, now has to pass before every release.

Beta.1 users get a notification about this release; download and install it over the old one.

## Shortcuts

`⌥⇧Z` capture an area · `⌘⇧9` full screen · `⌘⇧1` history · `⌘⇧2` settings (all changeable in Settings → Shortcuts).

## Install

**macOS (Apple Silicon only):** download `Snapkit-0.2.0-beta.2-mac-arm64.dmg`, open it and drag Snapkit to Applications.
Snapkit isn't signed with an Apple Developer ID yet, so macOS blocks the first launch:
open Snapkit once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
(Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Snapkit.app`.)
Then allow **Screen Recording** when asked, and quit and reopen Snapkit. After updating, macOS may ask for Screen Recording again.

**Windows (x64):** run `Snapkit-0.2.0-beta.2-win-x64-setup.exe`. SmartScreen warns about an unknown publisher: click **More info → Run anyway**.
The Windows build hasn't been tested by hand yet; please report anything odd.
