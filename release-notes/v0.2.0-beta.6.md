Sixth beta of Snapkit, a fast screenshot tool for macOS and Windows. A Windows fix.

## What's new since beta.5

- **Windows: the floating preview stays on top after an area capture.** With the floating preview on, the preview was created after copying but ended up behind the window you went back to (it only showed after minimizing something). It now stays on top, as it already did after a full-screen capture.
- Behind the scenes: a Windows test now asks Windows itself whether the preview is on top of the app you return to, at 100% and 150% display scaling.

Beta users get a notification about this release; download and install it over the old one.

## Shortcuts

`⌥⇧Z` (Windows: `Alt+Shift+Z`) capture an area · `⌘⇧9` full screen · `⌘⇧1` history · `⌘⇧2` settings (Windows: Ctrl instead of ⌘). All changeable in Settings → Shortcuts.

## Install

**macOS (Apple Silicon only):** download `Snapkit-0.2.0-beta.6-mac-arm64.dmg`, open it and drag Snapkit to Applications.
Snapkit isn't signed with an Apple Developer ID yet, so macOS blocks the first launch:
open Snapkit once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
(Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Snapkit.app`.)
Then allow **Screen Recording** when asked, and quit and reopen Snapkit. After updating, macOS may ask for Screen Recording again.

**Windows (x64):** run `Snapkit-0.2.0-beta.6-win-x64-setup.exe`. SmartScreen warns about an unknown publisher: click **More info → Run anyway**.
If something misbehaves, the log is at `%APPDATA%\Snapkit\logs\main.log`; please attach it to a bug report.
