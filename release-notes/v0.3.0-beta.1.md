First beta of Snapkit, a fast screenshot tool for macOS and Windows.

## What's new since beta.14

- **A native Mac app.** Snapkit for Mac is rewritten in Swift: it starts faster and uses much less memory and disk, with the same features, shortcuts, settings and history as before. It runs on Apple Silicon and Intel Macs with macOS 14 or newer. Your settings and history carry over.
- **Updates install from inside the app** on Mac: Snapkit shows what's new, downloads the update, checks its signature and restarts. Screen Recording permission stays granted across updates.
- **Text starting style: Light or Dark background.** Settings → Annotate → Text now offers Plain, Stroke, Light and Dark, the same choices as the style bar.
- **Steadier when things overlap:** two quick saves no longer overwrite each other, the clipboard always ends up with the newest copy, a text read finishing late no longer freezes the next capture, Capture Text is for text only, History only gets captures that were really copied or saved, and a pin saved twice quickly makes one file.
- **Floating preview buttons fit** at every size (on Windows the Text button used to be cut off). Text is now an icon button; its result shows at the bottom of the preview.

Beta users get a notification about this release; download and install it over the old one. On Mac, later updates install in place.

## Shortcuts

`⌥⇧Z` (Windows: `Alt+Shift+Z`) capture an area · `⌥⇧X` last area · `⌥⇧T` text (OCR) · `⌘⇧9` full screen · `⌘⇧1` history · `⌘⇧2` settings (Windows: Ctrl instead of ⌘). All changeable in Settings → Shortcuts.

## Install

**macOS 14 or newer (Apple Silicon or Intel):** download `Snapkit-0.3.0-beta.1-mac.dmg`, open it and drag Snapkit to Applications, replacing the old one.
Snapkit is signed with its own certificate, not a paid Apple Developer ID, so macOS blocks the first launch:
open Snapkit once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
(Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Snapkit.app`.)
Then allow **Screen Recording** when asked, and quit and reopen Snapkit. Coming from 0.2, macOS asks for Screen Recording once more; if captures only show the wallpaper, remove Snapkit from the list with – and add it back.

**Windows (x64):** run `Snapkit-0.3.0-beta.1-win-x64-setup.exe`. SmartScreen warns about an unknown publisher: click **More info → Run anyway**.
If something misbehaves, the log is at `%APPDATA%\Snapkit\logs\main.log`; please attach it to a bug report.
