Fifth beta of Snapkit, a fast screenshot tool for macOS and Windows.

## What's new since beta.4

- **New look:** Snapkit has its own icon now, the snapping hand. On macOS 26 and later the app icon is a real Liquid Glass icon (light, dark and tinted looks); older macOS and Windows get the same icon flat. The menu-bar icon (Mac) and tray icon (Windows) use it too.
- **Quick area capture** (Settings → General → After a capture, off by default): the area you draw is copied the moment you let go, with no adjusting or drawing step.
- **Editor zoom, continued:**
  - On a Mac, scrolling up (⌘ + scroll) now zooms in, like on Windows; a trackpad pinch works as before.
  - Hold **Space** and drag to move around a zoomed-in image, like Photoshop's hand tool.
  - Fast scrolling or pinching zooms the full amount (quick steps used to be partly lost).
- **Scrollbars** are thin and rounded with no background strip, in the theme's colors (the settings window had a white strip in the dark theme).

Beta users get a notification about this release; download and install it over the old one.

## Shortcuts

`⌥⇧Z` (Windows: `Alt+Shift+Z`) capture an area · `⌘⇧9` full screen · `⌘⇧1` history · `⌘⇧2` settings (Windows: Ctrl instead of ⌘). All changeable in Settings → Shortcuts.

## Install

**macOS (Apple Silicon only):** download `Snapkit-0.2.0-beta.5-mac-arm64.dmg`, open it and drag Snapkit to Applications.
Snapkit isn't signed with an Apple Developer ID yet, so macOS blocks the first launch:
open Snapkit once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
(Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Snapkit.app`.)
Then allow **Screen Recording** when asked, and quit and reopen Snapkit. After updating, macOS may ask for Screen Recording again.

**Windows (x64):** run `Snapkit-0.2.0-beta.5-win-x64-setup.exe`. SmartScreen warns about an unknown publisher: click **More info → Run anyway**.
If something misbehaves, the log is at `%APPDATA%\Snapkit\logs\main.log`; please attach it to a bug report.
