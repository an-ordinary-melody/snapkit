First public beta of Snapkit, a fast screenshot tool for macOS and Windows: hotkey → frozen screen → select → annotate → ⌘C.

## Highlights

- **Capture:** `⌥⇧Z` for an area, `⌘⇧5` for the whole screen (straight to the floating preview), from the menu bar too.
- **Annotate:** pencil, arrows (one-way or two-way), shapes, highlighter, text, numbered steps and blur. Smart alignment while moving; edit text in place.
- **Background:** gradient, color or image backgrounds with padding, corners, shadow and fixed output sizes.
- **Floating preview and pins:** copy, edit or pin the last capture; pins float above everything.
- **History:** `⌘⇧1` opens your recent captures (copy again, edit, pin, save, star, drag out as a file). Keeps 10 by default, up to 30.
- **Settings:** `⌘⇧2`. Light, Gray, Dark or System theme, optional Liquid Glass, every shortcut and tool configurable.
- Launch at login and update notifications (this beta is offered newer betas).

## Install

**macOS (Apple Silicon only):** download `Snapkit-0.2.0-beta.1-mac-arm64.dmg`, open it and drag Snapkit to Applications.
Snapkit isn't signed with an Apple Developer ID yet, so macOS blocks the first launch:
open Snapkit once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
(Or in Terminal: `xattr -dr com.apple.quarantine /Applications/Snapkit.app`.)
Then allow **Screen Recording** when asked, and quit and reopen Snapkit.

**Windows (x64):** run `Snapkit-0.2.0-beta.1-win-x64-setup.exe`. SmartScreen warns about an unknown publisher: click **More info → Run anyway**.
The Windows build hasn't been tested by hand yet; please report anything odd.

## Known limits

- Beta: please report bugs at https://github.com/sonbq-fsc/snapkit/issues.
- No Intel Mac build yet.
- `⌘⇧5` is also macOS's own screenshot shortcut; if the system toolbar opens instead, turn it off in System Settings → Keyboard → Keyboard Shortcuts → Screenshots, or pick another shortcut in Snapkit's settings.
